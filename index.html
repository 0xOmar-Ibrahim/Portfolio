Profile

I started at the register and worked my way up to the browser. That is why I read an application as a stack of things that can fail, not as a list of endpoints.

I'm an IT student and aspiring penetration tester, with hundreds of hours on Hack The Box (Skilled rank, Level 33, 14,310 XP), TryHackMe (top 7%) and the PortSwigger Web Security Academy.

I found and responsibly disclosed a critical IDOR on a live production website that exposed national IDs, names and photos, and I recently audited my own older code the same way.

My method covers the full lifecycle: reconnaissance, web enumeration, vulnerability validation, CVE analysis with tools like Metasploit and OpenVAS, then remediation advice a team can act on.

Alongside security, I shipped embedded and IoT systems at LABstar and wrote low-level software in C and x86-64 assembly. That background goes with me into every engagement.
